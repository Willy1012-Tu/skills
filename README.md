# skills

我自己用的 Claude skills，每个资料夹一个 skill。

| Skill | 用途 |
|---|---|
| [minimal-code](minimal-code/SKILL.md) | 写程序时只写解决问题所需的最少代码：不加多余功能、抽象、设置、注释与套件 |
| [plan-check-fix-rules](plan-check-fix-rules/SKILL.md) | 思考守则：处理多步骤任务时，依「规划 → 检查 → 修正」工作后再交出答案 |

## 使用

把想用的 skill 资料夹（含 `SKILL.md`）放到 Claude Code 的 `~/.claude/skills/` 下，
或压缩成 .zip 后到 claude.ai 的设置里上传为账号 skill。
